### On the engineering bench

- **[RavenAI](https://github.com/leoguolabs/RavenAI)** gives self-hosted agents access to a project’s repositories, tools, and devices so they can investigate a failed run and show the evidence behind a diagnosis.

### For readers and the spreadsheet-curious

- **LanRead (澜阅)** is an EPUB reader. Select a tricky passage for a translation or an explanation, then save a note alongside it. [Website](https://isla-reader.top/?lang=en) · [iPhone & iPad](https://github.com/leoguolabs/LanRead) · [Android](https://github.com/leoguolabs/LanRead-Android)
- **[Cognitrix](https://github.com/leoguolabs/Cognitrix)** lets you ask a question about an Excel workbook in plain language and explore the answer as a chart or dashboard.
